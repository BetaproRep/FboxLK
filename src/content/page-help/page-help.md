## Дашборд {#page:dashboard}

**Заказы, Поставка товаров, Отгрузка товаров**  - показывают ход выполнения ваших заданий на складе. Содержат информацию только о незавершенных входящих документах.

- `В ожидании` - входящие документы которые склад еще не взял в работу
- `В работе` - входящие документы которые склад уже взял в работу, но еще не завершил

Подробнее как создавать задания складу и отслеживать их выполнение смотри в [основной справке](/help?tab=documents).

**Скачать отчеты в Excel:** Отчеты в Excel содержат справочник товаров, текущие остатки, движение товаров и заказов в различных срезах. Они позволяют делать глубокую аналитику всех ваших процессов. Все отчеты обновляются прямо в Excel и не требуют повторного скачивания файлов.
Для работы с отчетами требуется версия *Excel 2016* или выше.

**Таблицы и графики:** Информация о товарах и заказах за последние два месяца. 
Данные в таблицах сгруппированы по периодам: за текущий день, с начала недели, с начала месяца. Для сравнения показаны соответствующие предыдущие периоды. Наведите мышь на график для получения информации за конкретный день. 
Используйте сглаживание графиков для выявления тенденций. 

## Быстрый старт {#page:quick-start}

Раздел состоит из **сценариев** (табы вверху страницы). Внутри сценария — **карточки**: длинные (краткий текст в сетке, полное описание по «Подробнее») и короткие (весь текст сразу в карточке).

Ссылки на сценарий в URL: `/quick-start?tab=<id сценария>`. Для открытой длинной карточки: `&card=<id карточки>`.

### Шаг: товары {#tab:quick-start:goods}

Сначала проверьте, что карточки товаров заполнены корректно и однозначно идентифицируют позиции.
Подробно: [Справка по товарам](/help?tab=goods).

### Шаг: поставка {#tab:quick-start:supply}

Создавайте задание на оприходование до прибытия машины, когда известны фактические количества.
Подробно: [Процесс поставки](/help?tab=supply#goods_supply_desc).

### Шаг: отслеживание поставки {#tab:quick-start:tracking-supply}

Контролируйте исходящие документы о начале и завершении приемки, включая частичные приемки.
Подробно: [Приемка частями](/help?tab=supply#goods_inpart_desc).

### Шаг: передача заказов {#tab:quick-start:orders}

Проверьте обязательные поля заказа и требования выбранной службы доставки.
Подробно: [Структура заказа](/help?tab=orders#order_struct_desc).

### Шаг: контроль обработки заказа {#tab:quick-start:tracking-orders}

Следите за стадиями обработки и сценариями возвратов, чтобы корректно интерпретировать статус.
Подробно: [Жизненный цикл заказа](/help?tab=orders#order_obr_desc).

### Карточка: быстрые переходы {#tab:quick-start:quick-links}

Короткая карточка без отдельного экрана: ссылки на разделы портала и основную справку.

## Входящие документы {#page:indocs}

Входящий документ - это ваше задание складу на выполнение определенных действий. 
Подробнее о входящих документах: [Справка — документооборот](/help?tab=documents).

Для создания документов используйте кнопки вверху справа `+ Задание на оприходование товаров`, `+ Задание на отгрузку товаров`, `+ Задание на отгрузку заказов` 

Для поиска нужных документов используйте фильтры:

**По дате создания:** режим по умолчанию — выберите период за который вы хотите получить документы 

**Незавершённые документы:** быстрый режим без выбора дат — только документы, которые склад ещё не выполнил. 

**По списку документов из буфера:** в этом режиме показываются документы с заданными номерами 
- если вы хотите найти конкретный документ, скопируйте его номер в буфер обмена и нажмите эту кнопку.
- если вы хотите поработать со списком конкретных документов, скопируйте список в буфер обмена и нажмите эту кнопку.
Списки документов удобно вставлять из Excel, для этого скопируйте ячейки с нужными номерами документов. Также можно скопировать диапазон из двух колонок - информация из второй колонки появится в поле *2я колонка буфера*, это удобно если вам нужна дополнительная информация для работы с документами.

**Поиск по списку...** — быстрый поиск среди уже загруженных в таблицу строк (номер, статус, тип, примечание).

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка.

Клик по строке открывает карточку входящего документа с подробной информацией.

### Задание на оприходование {#tab:indocs:create-goods-supply}

Форма создаёт входящий документ типа **задание на оприходование** — сообщение складу, какие товары и в каком количестве вы привозите. Создавайте задание, когда известны фактические количества, но до прибытия машины на склад.
Подробнее о процессе: [Поставка товаров на склад](/help?tab=supply#goods_supply_desc).

**Номер документа** — обязательное поле, введите уникальный номер создаваемого документа. Кнопка **Сгенерировать** подставляет номер вида `GS-ГГ-ММ-ДД-ЧЧММ`.

**Примечание** — необязательный комментарий к заданию.

**Товары** — список позиций для приёмки:
- **↓ Шаблон** — скачайте Excel-шаблон, заполните по интрукции в файле и скопируйте в буфер (заголовок, строка DSL-схемы, строки данных).
- **Вставить из буфера** — загрузка позиций из скопированного диапазона Excel; при ошибках в схеме или ячейках исправьте файл и повторите вставку.
- **+ Добавить позицию** — ручной ввод артикула и количества; после ввода артикула проверяется наличие товара в справочнике.

Для каждой строки: **артикул** (должен быть заведён на странице [Товары](/goods)), **количество** (целое, больше нуля). 

После **Создать документ** откроется карточка нового входящего документа.

### Задание на отгрузку товаров {#tab:indocs:create-goods-shipment}

Форма создаёт входящий документ **задание на отгрузку товаров** — запрос складу выдать указанные позиции со склада (например, для маркетплейса или перевозки).
Подробнее: [Отгрузка товаров со склада](/help?tab=goods#shipment).

**Номер документа** — обязательное поле, уникальный код в вашей системе. **Сгенерировать** подставляет номер вида `GH-ГГ-ММ-ДД-ЧЧММ`.

**Качество товара** — какой товар нормальный или бракованный нужно отгружать.

**Только подбор (без отгрузки)** — если нужны операции на складе без фактической отгрузки (например, фото или проверка брака).

**Примечание** — необязательный комментарий.

**Товары** — список позиций для отгрузки:
- **↓ Шаблон** — скачайте Excel-шаблон, заполните по интрукции в файле и скопируйте в буфер (заголовок, строка DSL-схемы, строки данных).
- **Вставить из буфера** — загрузка позиций из скопированного диапазона Excel; при ошибках в схеме или ячейках исправьте файл и повторите вставку.
- **+ Добавить позицию** — ручной ввод артикула и количества; после ввода артикула проверяется наличие товара в справочнике.

Для каждой строки: **артикул** (должен быть заведён на странице [Товары](/goods)), **количество** (целое, больше нуля). 

После **Создать документ** откроется карточка нового входящего документа.

### Задание на отгрузку заказов {#tab:indocs:create-orders-shipment}

Форма создаёт входящий документ **задание на отгрузку заказов** — передача складу списка заказов на комплектацию и отгрузку в службы доставки.
Подробнее: [Заказы](/help?tab=orders).

**Номер документа** — обязательное поле. **Сгенерировать** подставляет номер вида `OS-ГГ-ММ-ДД-ЧЧММ`.

**Примечание** — необязательный комментарий.

**Заказы** — загружаются  из шаблона:
- **↓ Шаблон** — скачайте Excel-шаблон, заполните по интрукции в файле и скопируйте в буфер (заголовок, строка DSL-схемы, строки данных).
- **Вставить из буфера** — загрузка позиций из скопированного диапазона Excel; при ошибках в схеме или ячейках исправьте файл и повторите вставку.
- **Очистить список** — сброс загруженных заказов.

После **Создать документ** откроется карточка нового входящего документа.

## Карточка входящего документа {#page:indoc-detail}

Карточка входящего документа — содержит детальную информацию по вашему заданию складу. 

В шапке — **тип документа**, **статус**, номер, дата создания, примечание. Также здесь могут быть указаны дополнительные атрибуты специфичные для определенных заданий.

**Удалить** — кнопка доступна только в статусе «Ожидание» (пока склад не начал работу над заданием).

Вкладки под шапкой зависят от типа документа: у заданий на поставку и отгрузку товаров — список позиций; у отгрузки заказов — список заказов. Подробнее о типах входящих документов: [Справка — документооборот](/help?tab=documents). 
Если перед названием активной вкладки есть иконка (?) нажмите ее для получения справки о вкладке.

### Товары {#tab:indoc-detail:goods}

Список позиций задания — для **оприходования** («Ожидаемые товары») или **отгрузки товаров** («Товары к отгрузке»). В заголовке вкладки в скобках — суммарное плановое количество.

Таблица: артикул, название, плановое количество. Также в таблице может отображаться **цена** и другие атрибуты связанные с товаром в задании.

Клик по строке открывает карточку товара.

### Заказы {#tab:indoc-detail:orders}

Список заказов в задании **на отгрузку заказов**: номер, статус, клиент, служба доставки, дата создания. Под строкой заказа — связанные **исходящие документы** склада по этому заказу.

Клик по строке открывает карточку заказа.

### Коробки {#tab:indoc-detail:boxes}

Для задания **выдачи из длительного хранения** — перечень идентификаторов коробок, которые склад должен выдать.

### Атрибуты {#tab:indoc-detail:attrs}

Дополнительные поля документа, заданные вами или складом: код атрибута, название, тип и значение.

### Исходящие документы {#tab:indoc-detail:outdocs}

Отчёты склада по выполнению этого задания: дата создания, дата документа, номер, тип операции.

Клик по строке открывает карточку исходящего документа. Подробнее: [Исходящие документы](/outdocs) и [Справка — документооборот](/help?tab=documents).

### Файлы {#tab:indoc-detail:files}
Файлы PDF прикрепленные к заданию. Если требуется, вы формируете документы в формате PDF и прикрепляете к заданию. Склад их распечатает и приложит к отгружаемому товару.

**Загрузить PDF** — прикрепить файл; по ссылке открывается скачивание; **Удалить** убирает файл с документа.

### Фото {#tab:indoc-detail:photos}
Фотографии, сделанные складом по заданию. Клик по изображению открывает полный размер; подпись может содержать ссылки на товар или заказ.

### JSON {#tab:indoc-detail:json}
Полное содержимое документа в формате JSON — для технической проверки или интеграции. Данные совпадают с ответом API по этому входящему документу.

## Исходящие документы {#page:outdocs}

Исходящий документ — отчёт склада о выполненной работе: приёмка и оприходование товаров, этапы обработки заказов, возвраты, оплаты и другие операции. Документы создаёт склад; в этом разделе вы просматриваете их список и детали.
Подробнее об исходящих документах и их типах: [Справка — документооборот](/help?tab=documents).

Для поиска нужных документов используйте фильтры:

**По дате создания:** режим по умолчанию — выберите период, за который нужно показать документы.

**Тип документа:** выпадающий список — оставьте «Все типы» или выберите конкретный вид операции (например, «Товары оприходованы», «Заказы отгружены в службу доставки»).

**Поиск по списку...** — быстрый поиск по уже загруженным в таблицу строкам (номер, тип, дата, примечание, связанное задание).

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка в файл.

**Блокировка:** галочка в строке — документ помечен как заблокированный для изменений со стороны склада

Под строкой исходящего документа может отображаться связанный **входящий документ** (ваше задание на основании котоорого склад выполнил работу). По ссылке на номер задания можно перейти на страницу с детальной информацией.

Для конкретных заказов набор исходящих документов удобнее смотреть на странице [Заказы](/orders) — там они показаны под каждым заказом.

## Карточка исходящего документа {#page:outdoc-detail}
Карточка исходящего документа — отчёт склада выполненной работе: «товары приняты»,
«заказы отгружены», «обнаружена недостача». Все изменения, которые произошли на складе с вашими
товарами или заказами, фиксируются исходящими документами. Подробнее о видах исходящих документов: [Справка — документооборот](/help?tab=documents).

В шапке — номер исходящего документа, дата операции, дата создания. Также здесь могут быть указаны дополнительные атрибуты специфичные для определенных операций. Если документ был создан на основании вашего задания, внизу шапки отображается ссылка на карточку входящего документа.

Набор **вкладок** зависит от типа исходящего документа: для оприходования — принятые товары; для отгрузки товаров — паллеты, короба и состав; для заказов — отправления или список заказов с дополнительными полями; для возвратов — возвращённые заказы и позиции. 
Если перед названием активной вкладки есть иконка (?) нажмите ее для получения справки о вкладке.

### Принятые товары {#tab:outdoc-detail:supply_goods}
На вкладке показываются фактически принятые позиции по сравнению с планом задания. Колонки: план, годное количество, брак, **разница** (зелёным — излишек, красным — недостача относительно плана).

Заголовки столбцов можно нажимать для сортировки. Клик по строке открывает карточку товара.

### Срок годности {#tab:outdoc-detail:supply_expiry}
На вкладке показываются товары принятые с учетом срока годности.
Подробнее об учете по сроку годности: [Справка — Срок годности](/help?tab=goods#good_expiry).

Клик по строке открывает карточку товара.

### Паллеты и короба {#tab:outdoc-detail:shipment_pallets}
Подобранные для отгрузки товары размещаются в короба. Каждому коробу склад присваивает идентификатор и наклеивает этикетку со штрихкодами. По согласованию склад может фиксировать размещение коробов на паллетах — тогда у каждой паллеты тоже появится свой идентификатор и этикетка. Подробнее об отгрузке товаров: [Справка — Отгрузка товаров со склада](/help?tab=goods#shipment).

В заголовке вкладки указано общее количество паллет/коробов/товаров 

Ниже идет детальная информация по каждому подобранному коробу

### Корректировка остатков {#tab:outdoc-detail:correction_goods}
Коррекцию выполняет склад если выявлено расхождение между учётным и фактическим количеством товара на складе. В зависимости от ситуации товар либо списывается, либо оприходуется, либо переводится в карантин. Подробнее о коррекции остатков: [Справка — Инвентаризация и коррекция](/help?tab=goods#goods_corr_desc).

### Отправления {#tab:outdoc-detail:shipments}
После того как заказ скомплектуют и упакуют появляется **Отправление**. Для отправления, в отличии от заказа известны его фактические габариты, вес, серийные номера и сроки годности подобранных товаров. Фактические данные по отправлению передаются в службу доставки, в ответ она возвращает штрихкод и трек-номер отправления. Отправления размещаются на паллеты и затем отгружаются в службу доставки. 
Подробнее: [Справка — Как склад обрабатывает заказы](/help?tab=orders#order_obr_desc).

Клик по строке открывает карточку заказа.

### Заказы {#tab:outdoc-detail:outdoc_orders}
Список заказов связанных с документом 

### Возвраты {#tab:outdoc-detail:return_orders}

Для **частичного** или **клиентского возврата** — по каждому возврату реквизиты заказа и при клиентском возврате штрихкоды посылки. Таблица возвращённых товаров: артикул, качество, количество, при необходимости срок годности и серийный номер.

### Движение товаров {#tab:outdoc-detail:goods}
Изменение остатков товаров на складе всегда подтверждается конкретным исходящим документом. Подробнее: [Справка — Остатки и движение товаров](/help?tab=goods#stock).

Эта вкладка информирует вас о том как изменились остатки в результате выполнения документа.

В таблице указывается: артикул, состояние доступности, качество и количество (на сколько изменились остатки) . 

Поле **Поиск по списку...** фильтрует строки без запроса к серверу.

### Серийные номера {#tab:outdoc-detail:sn}
Серийный номер — индивидуальный штрихкод экземпляра товара, используется, когда нужно отслеживать каждую штуку отдельно: маркировка «Честный знак», лекарства, электроника с гарантией.

Эта вкладка информирует вас о прибытии и выбытии серийных номеров на склад.

В таблице указывается: номер, артикул, приход или расход, качество, связанный заказ. 

Поиск по списку работает по всем отображаемым полям.

### Атрибуты {#tab:outdoc-detail:attrs}
Дополнительные поля документа, заданные вами или складом: код атрибута, название, тип и значение.


### Файлы {#tab:outdoc-detail:files}
Файлы PDF прикрепленные к документу. Если требуется, вы формируете документы в формате PDF и прикрепляете к документу или вашему заданию. Склад их распечатает и приложит к отгружаемому товару.

**Загрузить PDF** — прикрепить файл; по ссылке открывается скачивание; **Удалить** убирает файл с документа.

### Фото {#tab:outdoc-detail:photos}
Фотографии, сделанные складом. Клик по изображению открывает полный размер; подпись может содержать ссылки на товар или заказ.

### JSON {#tab:outdoc-detail:json}
Содержимое исходящего документа в формате JSON — для технической проверки или интеграции. 

## Товары {#page:goods}

Справочник товаров — карточки позиций, которые зарегистрированы на складе: артикул, название, тип, габариты, вес и другие атрибуты. Без зарегистрированных товаров нельзя передать поставку или заказ на отгрузку.
Подробнее о регистрации и характеристиках товаров: [Справка — товары](/help?tab=goods).

Для создания и обновления карточек нажмите кнопку `Загрузить номенклатуру` вверху справа: скачайте шаблон Excel, заполните данные и загрузите файл. Повторная загрузка с тем же артикулом обновляет характеристики товара.

Для поиска нужных позиций используйте фильтры:

**Название товара...** и кнопка **Найти** — поиск по названию на сервере. Указывайте слова или части слов в том порядке в котором они указаны в названии. Пробел между словами означает любые символы.
> Поиск `куртка кожа` найдет товар `Куртка женская кожанная`, но не найдет `Кожанная куртка` 
 
**Тип товара** — выпадающий список: товар, упаковка, листовка, услуга и т.д.

**По списку товаров из буфера:** в этом режиме показываются товары с заданными артикулами 
- если вы хотите найти конкретный товар, скопируйте артикул в буфер обмена и нажмите эту кнопку.
- если вы хотите поработать со списком конкретных товаров, скопируйте список артикулов в буфер обмена и нажмите эту кнопку.
Списки товаров удобно вставлять из Excel, для этого скопируйте ячейки с нужными артикулами. Также можно скопировать диапазон ячеек из двух колонок - информация из второй колонки появится в поле *2я колонка буфера*, это удобно если вам нужна дополнительная информация для работы с товарами.


**Поиск по списку...** — быстрый поиск среди уже загруженных в таблицу строк.

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка.

Клик по строке открывает карточку товара с подробной информацией.

### Загрузка номенклатуры {#tab:goods:upload-goods}

Форма создаёт или обновляет карточки товаров в справочнике склада. Минимум для каждой позиции — **артикул** и **название**; в шаблоне можно указать габариты, вес, штрихкоды и другие атрибуты.
Подробнее: [Регистрация товаров](/help?tab=goods#goods_reg).

**↓ Шаблон** — скачайте Excel-шаблон номенклатуры.

**Вставить из буфера** — скопируйте заполненный диапазон из Excel (строка заголовков, строка DSL-схемы, строки товаров). При ошибках в схеме или ячейках строка подсвечивается красным — исправьте файл и повторите вставку. Если список уже загружен, можно заменить его или добавить позиции из буфера.

**Очистить список** — удалить все подготовленные строки перед новой вставкой.

Повторная загрузка с тем же артикулом **обновляет** характеристики существующей карточки (артикул нельзя переназначить другому товару).

**Загрузить** — отправка списка на склад. После успеха форма закроется, справочник на странице [Товары](/goods) покажет список загруженных товаров.

## Карточка товара {#page:good-detail}
Карточка товара содержит детальную информацию о выбранном товаре. В заголовке указаны тип (товар, листовка, услуга) и название товара, под заголовком артикул, габариты, вес, типоразмер. Подробнее о товарах: [Справка — Товары](/help?tab=goods).

Блок **Остатки и резервы** над вкладками показывает доступное количество по качеству товара: свободный остаток (зелёный — есть, красный — нет) и резервы под заказы, подбор и отгрузку, карантин, длительное хранение. Пустые столбцы и строки с нулями скрываются. Подробнее об остатках: [Справка — Остатки и движение товаров](/help?tab=goods#stock).

Если перед названием активной вкладки есть иконка (?), нажмите её для справки по вкладке.

### Атрибуты {#tab:good-detail:info}
Дополнительные характеристики товара: код атрибута, название, тип и значение.

### Движение {#tab:good-detail:movements}
История изменений остатков по **исходящим документам** склада для этого артикула.

**Состояние товара** — складской остаток, карантин, долгое хранение; будут показаны документы которые изменили выбранное состояние.

**Период** — фильтр по дате операции; **Сбросить** очищает даты.

**Поиск...** — по номеру и типу документа, примечанию, качеству в уже загруженном списке.

**Экспорт Excel** — выгрузка отфильтрованной таблицы.

Клик по строке открывает карточку исходящего документа.

### Заказы {#tab:good-detail:orders}
Заказы, в составе которых есть этот товар.

**Незавершённые заказы** / **Все заказы** — режим загрузки списка.

**Поиск по списку...** — фильтр среди уже загруженных строк.

**Экспорт в Excel** — выгрузка таблицы.

Клик по строке открывает карточку заказа.

### EAN {#tab:good-detail:eans}
Штрихкоды (EAN), привязанные к товару при регистрации или обновлении номенклатуры.

### Фото {#tab:good-detail:photos}
Изображения товара. Клик открывает полный размер в новой вкладке.

### Серийные номера {#tab:good-detail:sn}
Серийный номер — индивидуальный штрихкод экземпляра товара, используется, когда нужно отслеживать каждую штуку отдельно: маркировка «Честный знак», лекарства, электроника с гарантией.

Таблица содержит серийные номера загруженные для этого товара и их статус.

## Заказы {#page:orders}

Заказ — это поручение собрать и отправить отправление конечному клиенту через выбранную службу доставки. На этой странице вы просматриваете список заказов, их статусы и связанные исходящие документы склада.
Подробнее о структуре заказа и жизненном цикле: [Справка — заказы](/help?tab=orders).

Для поиска нужных заказов используйте фильтры:

**По дате создания:** режим по умолчанию — выберите период, за который нужно показать заказы.

**Незавершённые заказы:** быстрый режим без выбора дат — только заказы, которые склад ещё не отгузил в службу доставки.

**По списку заказов из буфера:** в этом режиме показываются заказы с заданными номерами.
- если вы хотите найти конкретный заказ, скопируйте его номер в буфер обмена и нажмите эту кнопку.
- если вы хотите поработать со списком конкретных заказов, скопируйте список в буфер обмена и нажмите эту кнопку.
Списки удобно вставлять из Excel: скопируйте ячейки с номерами заказов. Также можно скопировать диапазон ячеек из двух колонок - информация из второй колонки появится в поле *2я колонка буфера*, это удобно если вам нужна дополнительная информация для работы с заказами.

**Поиск по списку...** — быстрый поиск среди уже загруженных в таблицу строк (номер, клиент, служба доставки, статус).

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка.

Под строкой заказа отображаются **исходящие документы** склада по этому заказу (этапы обработки, возвраты и т.д.). 

Клик по строке открывает карточку заказа с подробной информацией.

## Карточка заказа {#page:order-detail}
Карточка заказа содержит детальную информацию о выбранном заказе. В заголовке указаны номер заказа и его текущий статус. Под заголовком характеристики заказа, которые зависят от службы доставки и стадии обработки заказа. Подробнее о заказах: [Справка — Заказы](/help?tab=orders).

**Отменить** — отмена заказа на складе.

### Состав заказа {#tab:order-detail:goods}

Позиции, которые склад должен собрать: артикул, тип товара, название, количество, объявленная ценность и наложенный платёж по строке.

Клик по строке открывает [карточку товара](/goods).

### Исходящие документы {#tab:order-detail:outdocs}

Отчёты склада по этому заказу: приёмка, комплектация, отгрузка, возвраты, оплаты и др. — дата создания, дата документа, номер, тип.

Клик по строке открывает [карточку исходящего документа](/outdocs).

### События на складе {#tab:order-detail:events}

Хронология операций по заказу на складе: дата и описание события (статусы обработки, замечания).

### Отправление {#tab:order-detail:shipment}

Фактически сформированное **отправление** в службу доставки: по каждой единице (месту) — номер, штрихкод, упаковка, вес, габариты и таблица товаров в составе (с группировкой одинаковых строк). При необходимости отображаются серийный номер и срок годности.

Если отправление ещё не создано, вкладка покажет пустое состояние.

### Фото {#tab:order-detail:photos}

Фотографии, сделанные складом по заказу. Клик открывает изображение в полном размере.

### JSON {#tab:order-detail:json}

Полное содержимое заказа в формате JSON — для технической проверки или интеграции.
