## Дашборд {#page:dashboard}

**Заказы, Поставка товаров, Отгрузка товаров** — плитки показывают ход выполнения ваших заданий на складе. Содержат информацию только о незавершённых заданиях складу.

- `В ожидании` — задания складу, которые склад ещё не взял в работу
- `В работе` — задания складу, которые склад уже взял в работу, но ещё не завершил

Подробнее, как создавать задания складу и отслеживать их выполнение, смотрите в [основной справке](/help?tab=documents).

**Аналитические отчеты** — плитка с двумя разделами.

- **Google Таблицы:** нажмите пункт *Google Таблицы*, прочитайте инструкцию в окне и перейдите по ссылке «Создать копию шаблона». В копии откройте панель **FBox Отчёты**, войдите (код партнёра и пароль API, как в личном кабинете), выберите отчёт и нажмите **Обновить отчёт**. Данные загружаются с сервера на лист отчёта; повторно скачивать файл не нужно.

- **Отчеты в Excel:** список файлов для скачивания. Отчёты обновляются в Excel без повторного скачивания. Требуется *Excel 2016* или выше.

Подробнее смотрите в [Справка — Аналитика](/help?tab=analytics).

**Таблицы и графики:** Информация о товарах и заказах за последние два месяца. 
Данные в таблицах сгруппированы по периодам: за текущий день, с начала недели, с начала месяца. Для сравнения показаны соответствующие предыдущие периоды. Наведите мышь на график для получения информации за конкретный день. 
Используйте сглаживание графиков для выявления тенденций. 

## Задания складу {#page:indocs}

Задание складу — поручение выполнить определённые действия на складе.
Подробнее: [Справка — документооборот](/help?tab=documents).

Для создания заданий используйте кнопки вверху справа `+ Задание на оприходование товаров`, `+ Задание на отгрузку товаров`, `+ Задание на отгрузку заказов` 

Для поиска нужных заданий используйте фильтры:

**По дате создания:** режим по умолчанию — выберите период, за который вы хотите получить задания 

**Незавершённые задания:** быстрый режим без выбора дат — только задания, которые склад ещё не выполнил. 

**По списку заданий из буфера:** в этом режиме показываются задания с заданными номерами 
- если вы хотите найти конкретное задание, скопируйте его номер в буфер обмена и нажмите эту кнопку.
- если вы хотите поработать со списком конкретных заданий, скопируйте список в буфер обмена и нажмите эту кнопку.
Списки заданий удобно вставлять из Excel: скопируйте ячейки с нужными номерами. Также можно скопировать диапазон из двух колонок — информация из второй колонки появится в поле *2я колонка буфера*; это удобно, если вам нужна дополнительная информация для работы с заданиями.

**Быстрый поиск...** — поиск среди уже загруженных в таблицу строк (номер, статус, тип, примечание).

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка.

Клик по строке открывает карточку задания с подробной информацией.

### Задание на оприходование {#tab:indocs:create-goods-supply}

Форма создаёт задание на оприходование — сообщение складу, какие товары и в каком количестве вы привозите. Создавайте задание, когда известны фактические количества, но до прибытия машины на склад.
Подробнее о процессе: [Поставка товаров на склад](/help?tab=supply#goods_supply_desc).

**Номер задания** — обязательное поле; введите уникальный номер создаваемого задания. Кнопка **Сгенерировать** подставляет номер вида `GS-ГГ-ММ-ДД-ЧЧММ`.

**Примечание** — необязательный комментарий к заданию.

**Товары** — список позиций для приёмки:
- **↓ Шаблон** — скачайте Excel-шаблон, заполните по инструкции в файле и скопируйте в буфер (заголовок, строка DSL-схемы, строки данных).
- **Вставить из буфера** — загрузка позиций из скопированного диапазона Excel; при ошибках в схеме или ячейках исправьте файл и повторите вставку.
- **+ Добавить позицию** — ручной ввод артикула и количества; после ввода артикула проверяется наличие товара в справочнике.

Для каждой строки: **артикул** (должен быть заведён на странице [Товары](/goods)), **количество** (целое, больше нуля). 

После **Создать задание** откроется карточка нового задания.

### Задание на отгрузку товаров {#tab:indocs:create-goods-shipment}

Форма создаёт задание на отгрузку товаров — запрос складу выдать указанные позиции со склада (например, для маркетплейса или перевозки).
Подробнее: [Отгрузка товаров со склада](/help?tab=goods#shipment).

**Номер задания** — обязательное поле, уникальный код в вашей системе. **Сгенерировать** подставляет номер вида `GH-ГГ-ММ-ДД-ЧЧММ`.

**Качество товара** — какой товар нормальный или бракованный нужно отгружать.

**Только подбор (без отгрузки)** — если нужны операции на складе без фактической отгрузки (например, фото или проверка брака).

**Примечание** — необязательный комментарий.

**Товары** — список позиций для отгрузки:
- **↓ Шаблон** — скачайте Excel-шаблон, заполните по инструкции в файле и скопируйте в буфер (заголовок, строка DSL-схемы, строки данных).
- **Вставить из буфера** — загрузка позиций из скопированного диапазона Excel; при ошибках в схеме или ячейках исправьте файл и повторите вставку.
- **+ Добавить позицию** — ручной ввод артикула и количества; после ввода артикула проверяется наличие товара в справочнике.

Для каждой строки: **артикул** (должен быть заведён на странице [Товары](/goods)), **количество** (целое, больше нуля). 

После **Создать задание** откроется карточка нового задания.

### Задание на отгрузку заказов {#tab:indocs:create-orders-shipment}

Форма создаёт задание на отгрузку заказов — передача складу списка заказов на комплектацию и отгрузку в службы доставки.
Подробнее: [Заказы](/help?tab=orders).

**Номер задания** — обязательное поле. **Сгенерировать** подставляет номер вида `OS-ГГ-ММ-ДД-ЧЧММ`.

**Примечание** — необязательный комментарий.

**Заказы** — загружаются из шаблона:
- **↓ Шаблон** — скачайте Excel-шаблон, заполните по инструкции в файле и скопируйте в буфер (заголовок, строка DSL-схемы, строки данных).
- **Вставить из буфера** — загрузка позиций из скопированного диапазона Excel; при ошибках в схеме или ячейках исправьте файл и повторите вставку.
- **Очистить список** — сброс загруженных заказов.

После **Создать задание** откроется карточка нового задания.

## Карточка задания {#page:indoc-detail}

Карточка задания — детальная информация по вашему поручению складу.

В шапке — **тип задания**, **статус**, номер, дата создания, примечание. Также здесь могут быть указаны дополнительные атрибуты, специфичные для определённых заданий.

**Удалить** — кнопка доступна только в статусе «Ожидание» (пока склад не начал работу над заданием).

Вкладки под шапкой зависят от типа задания: у заданий на поставку и отгрузку товаров — список позиций; у отгрузки заказов — список заказов. Подробнее о типах заданий: [Справка — документооборот](/help?tab=documents). 
Если перед названием активной вкладки есть иконка (?), нажмите её для получения справки о вкладке.

### Товары {#tab:indoc-detail:goods}

Список позиций задания — для **оприходования** («Ожидаемые товары») или **отгрузки товаров** («Товары к отгрузке»). В заголовке вкладки в скобках — суммарное плановое количество.

Таблица: артикул, название, плановое количество. Также в таблице может отображаться **цена** и другие атрибуты, связанные с товаром в задании.

Клик по строке открывает карточку товара.

### Заказы {#tab:indoc-detail:orders}

Список заказов в задании **на отгрузку заказов**: номер, статус, клиент, служба доставки, дата создания. Под строкой заказа — связанные **отчёты склада** по этому заказу.

Клик по строке открывает карточку заказа.

### Коробки {#tab:indoc-detail:boxes}

Для задания **выдачи из длительного хранения** — перечень идентификаторов коробок, которые склад должен выдать.

### Атрибуты {#tab:indoc-detail:attrs}

Дополнительные поля задания, заданные вами или складом: код атрибута, название, тип и значение.

### Отчёты склада {#tab:indoc-detail:outdocs}

Отчёты склада по выполнению этого задания: дата создания, дата отчёта, номер, тип операции.

Клик по строке открывает карточку отчёта. Подробнее: [Отчёты склада](/outdocs) и [Справка — документооборот](/help?tab=documents).

### Файлы {#tab:indoc-detail:files}
Файлы PDF, прикреплённые к заданию. Если требуется, вы формируете документы в формате PDF и прикрепляете к заданию. Склад их распечатает и приложит к отгружаемому товару.

**Загрузить PDF** — прикрепить файл; по ссылке открывается скачивание; **Удалить** убирает файл с задания.

### Фото {#tab:indoc-detail:photos}
Фотографии, сделанные складом по заданию. Клик по изображению открывает полный размер; подпись может содержать ссылки на товар или заказ.

### JSON {#tab:indoc-detail:json}
Полное содержимое задания в формате JSON — для технической проверки или интеграции. Данные совпадают с ответом API по этому заданию.

## Отчёты склада {#page:outdocs}

Отчёт склада фиксирует выполненную работу: приёмку и оприходование товаров, этапы обработки заказов, возвраты, оплаты и другие операции. Отчёты создаёт склад; в этом разделе вы просматриваете их список и детали.
Подробнее о типах отчётов: [Справка — документооборот](/help?tab=documents).

Для поиска нужных отчётов используйте фильтры:

**По дате создания:** режим по умолчанию — выберите период, за который нужно показать отчёты.

**Тип отчёта:** выпадающий список — оставьте «Все типы» или выберите конкретный вид операции (например, «Товары оприходованы», «Заказы отгружены в службу доставки»).

**Быстрый поиск...** — быстрый поиск по уже загруженным в таблицу строкам (номер, тип, дата, примечание, связанное задание).

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка в файл.

**Блокировка:** галочка в строке — отчёт помечен как заблокированный для изменений со стороны склада

Под строкой отчёта может отображаться связанное **задание**, на основании которого склад выполнил работу. По ссылке на номер задания можно перейти на страницу с детальной информацией.

Для конкретных заказов набор отчётов удобнее смотреть на странице [Заказы](/orders) — там они показаны под каждым заказом.

## Карточка отчёта склада {#page:outdoc-detail}

Карточка отчёта — детали выполненной складом работы: «товары приняты», «заказы отгружены», «обнаружена недостача» и т. п. Подробнее о видах отчётов: [Справка — документооборот](/help?tab=documents).

В шапке — номер отчёта, дата операции, дата создания. Также здесь могут быть указаны дополнительные атрибуты, специфичные для определённых операций. Если отчёт создан на основании вашего задания, внизу шапки отображается ссылка на карточку задания.

Набор **вкладок** зависит от типа отчёта: для оприходования — принятые товары; для отгрузки товаров — паллеты, короба и состав; для заказов — отправления или список заказов с дополнительными полями; для возвратов — возвращённые заказы и позиции. 
Если перед названием активной вкладки есть иконка (?), нажмите её для получения справки о вкладке.

### Принятые товары {#tab:outdoc-detail:supply_goods}
На вкладке показываются фактически принятые позиции по сравнению с планом задания. Колонки: план, годное количество, брак, **разница** (зелёным — излишек, красным — недостача относительно плана).

Заголовки столбцов можно нажимать для сортировки. Клик по строке открывает карточку товара.

### Срок годности {#tab:outdoc-detail:supply_expiry}
На вкладке показываются товары, принятые с учётом срока годности.
Подробнее об учёте по сроку годности: [Справка — Срок годности](/help?tab=goods#good_expiry).

Клик по строке открывает карточку товара.

### Паллеты и короба {#tab:outdoc-detail:shipment_pallets}
Подобранные для отгрузки товары размещаются в короба. Каждому коробу склад присваивает идентификатор и наклеивает этикетку со штрихкодами. По согласованию склад может фиксировать размещение коробов на паллетах — тогда у каждой паллеты тоже появится свой идентификатор и этикетка. Подробнее об отгрузке товаров: [Справка — Отгрузка товаров со склада](/help?tab=goods#shipment).

В заголовке вкладки указано общее количество паллет/коробов/товаров.

Ниже идёт детальная информация по каждому подобранному коробу.

### Корректировка остатков {#tab:outdoc-detail:correction_goods}
Коррекцию выполняет склад, если выявлено расхождение между учётным и фактическим количеством товара на складе. В зависимости от ситуации товар либо списывается, либо оприходуется, либо переводится в карантин. Подробнее о коррекции остатков: [Справка — Инвентаризация и коррекция](/help?tab=goods#goods_corr_desc).

### Отправления {#tab:outdoc-detail:shipments}
После того как заказ скомплектуют и упакуют, появляется **Отправление**. Для отправления, в отличие от заказа, известны его фактические габариты, вес, серийные номера и сроки годности подобранных товаров. Фактические данные по отправлению передаются в службу доставки, в ответ она возвращает штрихкод и трек-номер отправления. Отправления размещаются на паллеты и затем отгружаются в службу доставки. 
Подробнее: [Справка — Как склад обрабатывает заказы](/help?tab=orders#order_obr_desc).

Клик по строке открывает карточку заказа.

### Заказы {#tab:outdoc-detail:outdoc_orders}
Список заказов, связанных с отчётом.

### Возвраты {#tab:outdoc-detail:return_orders}

Для **частичного** или **клиентского возврата** — по каждому возврату реквизиты заказа и при клиентском возврате штрихкоды посылки. Таблица возвращённых товаров: артикул, качество, количество, при необходимости срок годности и серийный номер.

### Движение товаров {#tab:outdoc-detail:goods}
Изменение остатков товаров на складе всегда подтверждается конкретным отчётом склада. Подробнее: [Справка — Остатки и движение товаров](/help?tab=goods#stock).

Эта вкладка информирует вас о том, как изменились остатки в результате выполнения операции.

В таблице указывается: артикул, состояние доступности, качество и количество (на сколько изменились остатки).

Поле **Быстрый поиск...** фильтрует строки без запроса к серверу.

### Серийные номера {#tab:outdoc-detail:sn}
Серийный номер — индивидуальный штрихкод экземпляра товара, используется, когда нужно отслеживать каждую штуку отдельно: маркировка «Честный знак», лекарства, электроника с гарантией.

Эта вкладка информирует вас о прибытии и выбытии серийных номеров на склад.

В таблице указывается: номер, артикул, приход или расход, качество, связанный заказ. 

Поиск по списку работает по всем отображаемым полям.

### Атрибуты {#tab:outdoc-detail:attrs}
Дополнительные поля, заданные вами или складом: код атрибута, название, тип и значение.


### Файлы {#tab:outdoc-detail:files}
Файлы PDF, прикреплённые к отчёту. Если требуется, вы формируете документы в формате PDF и прикрепляете к отчёту. Склад их распечатает и приложит к отгружаемому товару.

**Загрузить PDF** — прикрепить файл; по ссылке открывается скачивание; **Удалить** удаляет файл из отчёта.

### Фото {#tab:outdoc-detail:photos}
Фотографии, сделанные складом. Клик по изображению открывает полный размер; подпись может содержать ссылки на товар или заказ.

### JSON {#tab:outdoc-detail:json}
Содержимое отчёта в формате JSON — для технической проверки или интеграции. 

## Товары {#page:goods}

Справочник товаров — карточки позиций, которые зарегистрированы на складе: артикул, название, тип, габариты, вес и другие атрибуты. Без зарегистрированных товаров нельзя передать поставку или заказ на отгрузку.
Подробнее о регистрации и характеристиках товаров: [Справка — товары](/help?tab=goods).

Для создания и обновления карточек нажмите кнопку `Загрузить номенклатуру` вверху справа: скачайте шаблон Excel, заполните данные и загрузите файл. Повторная загрузка с тем же артикулом обновляет характеристики товара.

Для поиска нужных позиций используйте фильтры:

**Название товара...** и кнопка **Найти** — поиск по названию на сервере. Указывайте слова или части слов в том порядке, в котором они указаны в названии. Пробел между словами означает любые символы.
> Поиск `куртка кожа` найдёт товар `Куртка женская кожаная`, но не найдёт `Кожаная куртка` 
 
**Тип товара** — выпадающий список: товар, упаковка, листовка, услуга и т.д.

**По списку товаров из буфера:** в этом режиме показываются товары с заданными артикулами 
- если вы хотите найти конкретный товар, скопируйте артикул в буфер обмена и нажмите эту кнопку.
- если вы хотите поработать со списком конкретных товаров, скопируйте список артикулов в буфер обмена и нажмите эту кнопку.
Списки товаров удобно вставлять из Excel, для этого скопируйте ячейки с нужными артикулами. Также можно скопировать диапазон ячеек из двух колонок — информация из второй колонки появится в поле *2я колонка буфера*; это удобно, если вам нужна дополнительная информация для работы с товарами.


**Быстрый поиск...** — поиск среди уже загруженных в таблицу строк.

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка.

Клик по строке открывает карточку товара с подробной информацией.

### Загрузка номенклатуры {#tab:goods:upload-goods}

Форма создаёт или обновляет карточки товаров в справочнике склада. Минимум для каждой позиции — **артикул** и **название**; в шаблоне можно указать габариты, вес, штрихкоды и другие атрибуты.
Подробнее: [Регистрация товаров](/help?tab=goods#goods_reg).

**↓ Шаблон** — скачайте Excel-шаблон номенклатуры.

**Вставить из буфера** — скопируйте заполненный диапазон из Excel (строка заголовков, строка DSL-схемы, строки товаров). При ошибках в схеме или ячейках строка подсвечивается красным — исправьте файл и повторите вставку. Если список уже загружен, можно заменить его или добавить позиции из буфера.

**Очистить список** — удалить все подготовленные строки перед новой вставкой.

Повторная загрузка с тем же артикулом **обновляет** характеристики существующей карточки (артикул нельзя переназначить другому товару).

**Загрузить** — отправка списка на склад. После успеха форма закроется, справочник на странице [Товары](/goods) покажет список загруженных товаров.

## Карточка товара {#page:good-detail}
Карточка товара содержит детальную информацию о выбранном товаре. В заголовке указаны тип (товар, листовка, услуга) и название товара, под заголовком артикул, габариты, вес, типоразмер. Подробнее о товарах: [Справка — Товары](/help?tab=goods).

Блок **Остатки и резервы** над вкладками показывает доступное количество по качеству товара: свободный остаток (зелёный — есть, красный — нет) и резервы под заказы, подбор и отгрузку, карантин, длительное хранение. Пустые столбцы и строки с нулями скрываются. Подробнее об остатках: [Справка — Остатки и движение товаров](/help?tab=goods#stock).

Если перед названием активной вкладки есть иконка (?), нажмите её для справки по вкладке.

### Атрибуты {#tab:good-detail:info}
Дополнительные характеристики товара: код атрибута, название, тип и значение.

### Движение {#tab:good-detail:movements}
История изменений остатков по **отчётам склада** для этого артикула.

**Состояние товара** — складской остаток, карантин, долгое хранение; будут показаны отчёты, в которых изменилось выбранное состояние.

**Период** — фильтр по дате операции; **Сбросить** очищает даты.

**Быстрый поиск...** — поиск по номеру и типу отчёта, примечанию, качеству в уже загруженном списке.

**Экспорт Excel** — выгрузка отфильтрованной таблицы.

Клик по строке открывает карточку отчёта склада.

### Заказы {#tab:good-detail:orders}
Заказы, в составе которых есть этот товар.

**Незавершённые заказы** / **Все заказы** — режим загрузки списка.

**Быстрый поиск...** — фильтр среди уже загруженных строк.

**Экспорт в Excel** — выгрузка таблицы.

Клик по строке открывает карточку заказа.

### EAN {#tab:good-detail:eans}
Штрихкоды (EAN), привязанные к товару при регистрации или обновлении номенклатуры.

### Фото {#tab:good-detail:photos}
Изображения товара. Клик открывает полный размер в новой вкладке.

### Серийные номера {#tab:good-detail:sn}
Серийный номер — индивидуальный штрихкод экземпляра товара, используется, когда нужно отслеживать каждую штуку отдельно: маркировка «Честный знак», лекарства, электроника с гарантией.

Таблица содержит серийные номера, загруженные для этого товара, и их статус.

## Заказы {#page:orders}

Заказ — это поручение собрать и отправить отправление конечному клиенту через выбранную службу доставки. На этой странице вы просматриваете список заказов, их статусы и связанные отчёты склада.
Подробнее о структуре заказа и жизненном цикле: [Справка — заказы](/help?tab=orders).

Для поиска нужных заказов используйте фильтры:

**По дате создания:** режим по умолчанию — выберите период, за который нужно показать заказы.

**Незавершённые заказы:** быстрый режим без выбора дат — только заказы, которые склад ещё не отгрузил в службу доставки.

**По списку заказов из буфера:** в этом режиме показываются заказы с заданными номерами.
- если вы хотите найти конкретный заказ, скопируйте его номер в буфер обмена и нажмите эту кнопку.
- если вы хотите поработать со списком конкретных заказов, скопируйте список в буфер обмена и нажмите эту кнопку.
Списки удобно вставлять из Excel: скопируйте ячейки с номерами заказов. Также можно скопировать диапазон ячеек из двух колонок — информация из второй колонки появится в поле *2я колонка буфера*; это удобно, если вам нужна дополнительная информация для работы с заказами.

**Быстрый поиск...** — поиск среди уже загруженных в таблицу строк (номер, клиент, служба доставки, статус).

**Экспорт в Excel** — выгрузка текущего отфильтрованного списка.

Под строкой заказа отображаются **отчёты склада** по этому заказу (этапы обработки, возвраты и т.д.). 

Клик по строке открывает карточку заказа с подробной информацией.

## Карточка заказа {#page:order-detail}
Карточка заказа содержит детальную информацию о выбранном заказе. В заголовке указаны номер заказа и его текущий статус. Под заголовком характеристики заказа, которые зависят от службы доставки и стадии обработки заказа. Подробнее о заказах: [Справка — Заказы](/help?tab=orders).

**Отменить** — отмена заказа на складе.

### Состав заказа {#tab:order-detail:goods}
Позиции, которые склад должен собрать: артикул, тип товара, название, количество, объявленная ценность и наложенный платёж по строке.

Клик по строке открывает карточку товара.

### Отчёты склада {#tab:order-detail:outdocs}
Отчёты склада показывают, какие операции склад выполнил по этому заказу: комплектация, отгрузка, возвраты, оплаты и др. — дата создания, дата отчёта, номер, тип.

Клик по строке открывает карточку отчёта.

### События на складе {#tab:order-detail:events}
Хронология операций по заказу на складе: дата и описание события (статусы обработки, замечания).

### Отправление {#tab:order-detail:shipment}
После того как заказ скомплектуют и упакуют, появляется **Отправление**. Для отправления, в отличие от заказа, известны его фактические габариты, вес, серийные номера и сроки годности подобранных товаров. Фактические данные по отправлению передаются в службу доставки, в ответ она возвращает штрихкод и трек-номер отправления. 
Подробнее: [Справка — Как склад обрабатывает заказы](/help?tab=orders#order_obr_desc).


Если отправление ещё не создано, вкладка покажет пустое состояние.

### Фото {#tab:order-detail:photos}
Фотографии, сделанные складом по заказу. Клик открывает изображение в полном размере.

### JSON {#tab:order-detail:json}
Полное содержимое заказа в формате JSON — для технической проверки или интеграции.
