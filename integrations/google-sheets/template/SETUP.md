# Чеклист эталонной Google Таблицы

## 1. Структура мастер-копии

- **Один лист:** `Инструкция`
- Текст в ячейках (пример):

  1. Откройте ссылку с портала и нажмите **Создать копию**.
  2. Справа откроется панель **FBox Отчёты** (или меню **FBox Отчёты → Открыть панель**).
  3. Введите код партнёра и пароль API (как в личном кабинете), нажмите **Войти**.
  4. Выберите отчёт, укажите параметры, нажмите **Обновить отчёт**.
  5. Данные появятся на листе вида `1 - Название отчёта`.

- **Снимок с другими параметрами:** переименуйте лист отчёта перед следующим обновлением — скрипт создаст новый лист с каноническим именем, старый не тронет.
- **Копия листа** (через контекстное меню) не обновляется скриптом.

Не создавайте листы «Настройки» / «Отчет» — они больше не используются.

## 2. Apps Script

1. **Расширения → Apps Script** в этой таблице.
2. `clasp push` из `integrations/google-sheets`.
3. **Сервисы** → **Google Sheets API** → Добавить.
4. При первом запуске — разрешения Google; затем снова откройте таблицу.

## 3. Публикация

- Ссылка: `https://docs.google.com/spreadsheets/d/{ID}/copy`
- В портале: `VITE_GOOGLE_SHEETS_TEMPLATE_URL` или `google_sheets_reports` в API дашборда.

## 4. Проверка

- [ ] Сайдбар открывается при открытии файла
- [ ] Неверный пароль → ошибка в строке авторизации
- [ ] Успешный вход → список отчётов, описание, сохранённые параметры
- [ ] Лист `N - …` с A1/A2 и таблицей с 3-й строки
- [ ] Переименованный лист отчёта не перезаписывается
