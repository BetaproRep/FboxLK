# FBox — отчёты в Google Таблицах

Apps Script: панель **FBox Отчёты** (сайдбар), загрузка из `POST /grh/api/reports`, каталог `GET /grh/api/reports/catalog`.

## Быстрый старт (разработчик)

1. `cd integrations/google-sheets && npm install`
2. `npx clasp login`
3. Мастер-таблица: один лист **Инструкция** → **Расширения → Apps Script**
4. **Сервисы** (+) → **Google Sheets API** (для умной таблицы)
5. `.clasp.json` из `.clasp.json.example` с `scriptId`
6. `npm run push`

> **clasp `access_token`:** используйте `@google/clasp` 3.x из проекта (`npx clasp login`).
> **«Нет функций» в редакторе:** запускайте функции из **Triggers.gs**, не из Code.gs.

## Сценарий пользователя

1. Ссылка `/copy` с портала → копия в Drive пользователя.
2. При открытии — сайдбар **FBox Отчёты** (installable-триггер `onSpreadsheetOpen` после первой авторизации; иначе **FBox Отчёты → Открыть панель**). После `push`: **Войти** в панели или **Открыть панель** из меню — Google запросит разрешения; затем сайдбар будет открываться при каждом открытии файла.
3. **Войти** (код партнёра + пароль) — проверка через загрузку каталога API.
4. Выбрать отчёт, параметры, **Обновить отчёт**.
5. Данные на листе `{report_id} - {name}`: строка 1 — описание, 2 — параметры, с 3-й — таблица.

### Листы пользователя

- Скрипт обновляет только лист с **каноническим именем** (`1 - Задания складу`).
- **Копия** листа (`Копия …`) или **переименованный** лист не изменяется.
- Чтобы сохранить снимок с другими параметрами: переименуйте лист до следующего обновления того же `report_id`.

## Профилирование загрузки

После **Обновить отчёт** в сайдбаре: «Готово…» и кнопка **…** — по клику раскрывается разбивка по этапам (`write_values_api` / `write_values_setValues` и др.).

Тот же лог пишется в **Apps Script → Выполнения** (Executions), фильтр `[FBox profile]`. Полезно, если сайдбар закрыли до конца.

Типичные этапы:

| Этап | Что происходит |
|------|----------------|
| `api_fetch` | HTTP-запросы к `/reports` (пагинация) |
| `build_matrix` | Сборка двумерного массива в памяти скрипта |
| `write_values` | `setValues` — запись ячеек в таблицу |
| `table_layout` | Умная таблица (`addTable`) или автофильтр |
| `column_width` | Подбор ширины по первым 500 строкам |
| `activate_sheet` | Переключение на лист отчёта |

**Большие отчёты:** порог умной таблицы — `SMART_TABLE_MAX_DATA_ROWS` в `config.ts` (`0` = всегда создавать через API). Автопереключение листа отключается выше `SKIP_ACTIVATE_SHEET_ABOVE_ROWS` (5000).

Если «Готово» уже видно, а вкладка тормозит — скрипт завершился; тормозит **интерфейс Google Таблиц** при отрисовке большого листа (это не попадает в профиль).
