ОПИСАНИЕ ЯЗЫКА DSL ДЛЯ ШАБЛОНОВ EXCEL
=======================================

Каждый шаблон Excel содержит служебную строку (обычно строка 2), где для каждой
колонки описано правило: что туда вводить, какого типа данные, обязательно ли
поле и как его значение попадёт в систему.

Формат записи для одной колонки:

    путь.к.полю:тип[модификаторы]


-----------------------------------------------------------------------
ТИПЫ ДАННЫХ
-----------------------------------------------------------------------

    str     Текст (любая строка)
    int     Целое число (без дроби)
    num     Число с дробной частью
    bool    Да/Нет. Принимает: 1, да, yes, true / 0, нет, no, false


-----------------------------------------------------------------------
ПУТЬ К ПОЛЮ
-----------------------------------------------------------------------

Простое поле:
    order_id:str            → поле order_id в корне объекта

Вложенное поле (через точку):
    client.name:str         → поле name внутри блока client
    address.city:str        → поле city внутри блока address
    client.address.zip:str  → допускается несколько уровней вложенности


-----------------------------------------------------------------------
МАССИВЫ ОБЪЕКТОВ — квадратные скобки []
-----------------------------------------------------------------------

Используется когда в одном заказе несколько товаров, каждый товар —
отдельная строка в Excel.

    goods[].good_id:str     → поле good_id каждого товара в списке goods
    goods[].price:num       → цена того же товара

Все поля с одним и тем же именем до [] образуют один список.
Строки Excel группируются в один заказ по полю-идентификатору (см. ! ниже).

Вложенный массив:
    dev101.products[].name:str   → список products внутри блока dev101


-----------------------------------------------------------------------
МОДИФИКАТОРЫ
-----------------------------------------------------------------------

Записываются после типа, порядок произвольный.


* — ОБЯЗАТЕЛЬНОЕ ПОЛЕ
    Если ячейка пуста — ошибка при загрузке, строка не принимается.

    order_id:str*
    goods[].good_id:str*


= — ЗНАЧЕНИЕ ПО УМОЛЧАНИЮ
    Подставляется автоматически если ячейка пуста.

    goods[].vat_rate:int=20      → НДС 20% если не указан
    payment_type:str=CARD        → тип оплаты CARD если не указан
    goods[].qnt:int^=1           → количество 1 если не указано


! — ИДЕНТИФИКАТОР ОБЪЕКТА
    Обязателен в шаблонах со списками товаров [].
    Смена значения в этой колонке означает начало нового заказа.
    Ровно одна колонка в шаблоне должна иметь этот модификатор.

    order_id:str*!


^ — КОЛИЧЕСТВО КОПИЙ (только для полей списка)
    Поле не передаётся в систему. Его числовое значение задаёт
    сколько раз товар попадёт в список. Удобно когда нужно добавить
    несколько одинаковых товаров.

    goods[].qnt:int^        → 3 в этой ячейке → товар добавится 3 раза
    goods[].qnt:int^=1      → то же, но если пусто — одна копия


+ — МАССИВ СКАЛЯРОВ ЧЕРЕЗ ЗАПЯТУЮ
    Несколько значений вводятся в одну ячейку через запятую.
    Система разбивает их на отдельные элементы списка.
    Проверки типа и формата применяются к каждому значению.

    eans:str+               → "1234567890123, 1234567890124"
                              ↓
                              eans: ["1234567890123", "1234567890124"]

    codes:int+              → "1, 2, 3"  →  codes: [1, 2, 3]

    Совместим с другими модификаторами:
    eans:str+*              → обязательный массив EAN
    eans:str+{шаблон~...}   → проверка формата для каждого EAN


(список) — ДОПУСТИМЫЕ ЗНАЧЕНИЯ
    Если введено значение не из списка — ошибка. Регистр не важен.
    Значения перечисляются через запятую без пробелов.

    mail_type:int(4,23,24)          → только коды 4, 23 или 24
    payment_type:str(CARD,CASH)     → только CARD или CASH (card тоже ОК)
    goods[].vat_rate:int(0,10,20)   → НДС только 0%, 10% или 20%

    Совместим с * и =:
    mail_type:int(4,23,24)*=4       → обязателен, по умолчанию 4


{шаблон~сообщение} — ПРОВЕРКА ФОРМАТА
    Значение должно соответствовать заданному шаблону (регулярное
    выражение). После знака ~ — текст ошибки который увидит пользователь.

    address.zip:str{^\d{6}$~Индекс должен содержать ровно 6 цифр}
    client.phone:str{^\+7\d{10}$~Телефон в формате +7XXXXXXXXXX}
    barcode:str{^\d{13}$~Штрихкод должен содержать ровно 13 цифр}

    Если текст ошибки не указан — показывается сам шаблон.

    Совместим с * и +.


-----------------------------------------------------------------------
СОВМЕСТИМОСТЬ МОДИФИКАТОРОВ
-----------------------------------------------------------------------

Все модификаторы можно комбинировать. Порядок в строке не важен.

    goods[].qnt:int*^=1
        обязательное поле ^ количество копий, по умолчанию 1

    mail_type:int(4,23,24)*=4
        обязательное поле, только из списка, по умолчанию 4

    eans:str+*{^\d{13}$~EAN должен содержать ровно 13 цифр}
        обязательный массив EAN через запятую, каждый — 13 цифр

    address.zip:str{^\d{6}$~...}*
        обязательный индекс, строго 6 цифр

    goods[].vat_rate:int(0,10,20)=20
        НДС из списка, по умолчанию 20


-----------------------------------------------------------------------
ПРИМЕР ПОЛНОЙ DSL-СТРОКИ
-----------------------------------------------------------------------

Колонки шаблона заказов:

    order_id:str*!
    delivery_id:int(101,102,201)*
    client.name:str*
    client.phone:str{^\+7\d{10}$~Телефон в формате +7XXXXXXXXXX}
    address.zip:str{^\d{6}$~Индекс — 6 цифр}
    goods[].good_id:str*
    goods[].declared_value:num*
    goods[].cod:num=0
    goods[].qnt:int^=1
    goods[].eans:str+

Что здесь происходит:
    - order_id    — обязателен, определяет границу нового заказа
    - delivery_id — обязателен, только коды 101, 102 или 201
    - client.name — обязателен
    - client.phone — по желанию, но если указан — проверяется формат
    - address.zip  — по желанию, если указан — строго 6 цифр
    - good_id      — обязателен для каждого товара
    - cod          — наложенный платёж, если пусто — 0
    - qnt          — сколько копий товара добавить, если пусто — 1
    - eans         — EAN-коды товара, несколько через запятую


-----------------------------------------------------------------------
КАК ЧИТАТЬ СООБЩЕНИЯ ОБ ОШИБКАХ
-----------------------------------------------------------------------

При загрузке шаблона система сообщает о каждой ошибке:

    Поле          — техническое имя поля (из DSL), например "goods[].vat_rate"
    Колонка       — название колонки из заголовка Excel
    Строка        — номер строки в файле
    Сообщение     — что именно не так

Типичные сообщения:

    "обязательное поле не заполнено"
        → ячейка пуста, а поле отмечено *

    "ожидается целое число, получено «abc»"
        → в поле типа int введён текст

    "недопустимое значение «99», ожидается одно из: 4, 23, 24"
        → значение не входит в список ()

    "недопустимое значение «12345». Индекс должен содержать ровно 6 цифр"
        → значение не соответствует шаблону {}

    "элемент 2: EAN должен содержать ровно 13 цифр"
        → второй EAN в ячейке со списком не прошёл проверку
